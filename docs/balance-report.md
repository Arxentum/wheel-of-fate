# 平衡报告

> 由 `npm run sim` 生成：共 366,000 局电脑对局，用时 472 秒，总种子 `wof`（同一种子可完整复现）。
> - **v3**：规则书 v3 原样。
> - **v4**：M1 采纳的建议版（轮换先手、单体逆位打所有领先者、18 处角色数值，D-58）。
> - **v5（现行，引擎默认值）**：v4 + 护盾返还（D-59）+ 角色逆位重设计和新陷阱规则（D-60 – D-63）。
> 角色胜率以各人数 3 圈 20,000 局为准（3 人局每个角色约 2727 个样本，95% 误差约 ±1.8 个百分点）。平衡目标：3 人局每个角色在公平值 ±5 个百分点内，2 / 4 人局 ±8 内。

## 结论

**3 人 3 圈（默认）三版对比**

| 指标 | v3 | v4 | v5（现行） | 目标 |
| --- | --- | --- | --- | --- |
| 按行动顺序的胜率 | 26% / 33% / 41% | 34% / 33% / 33% | 34% / 32% / 34% | 各约 33% |
| 角色胜率最大偏离 | ±19.6 | ±6.9 | ±4.4 | ±5 以内 |
| 超出 ±5 的角色数 | 20 | 2 | 0 | 0 |
| 角色技能用逆位的比例 | 9% | 4% | 26% | 25%–40% |
| 正位占比：小阿卡纳 / 宫廷 | 97% / 77% | 78% / 76% | 78% / 77% | 25%–75% |
| 每局陷阱触发 | 0.06 | 0.02 | 0.34 | ≥ 0.3 |
| 平均轮数 | 8.6 | 8.9 | 10.6 | 8–12；比 v4 多约 1.5 轮以内可接受 |

1. **默认 3 圈。** v5 的 3 人局平均 10.6 轮，比 v4 多 1.7 轮（已接受多约 1.5 轮）。原因：要让电脑愿意用逆位，逆位让对手后退的格数大约要是正位自己前进的两倍，每多用一次逆位，全场的总进度就少几格（§4.3）。
2. **角色平衡**：3 人局超出 ±5 的角色 0 个；2 人局超出 ±8 的 1 个（12 倒吊人 +8.1）；4 人局 0 个。
3. **逆位真正有用了**：3 人局角色技能用逆位 26%（v4 4%）；「一律用逆位」的电脑平均胜率从 v4 的 7.1% 升到 24.5%（§4.4）。
4. **陷阱回来了**：每局触发 0.34 次（v4 0.02）。
5. **仍未解决**：3 人局小阿卡纳正位 78%，略超 75%（2、4 人局在范围内）。试过把「打领先者 +1」也用到小牌和宫廷牌上，3 人局降到约 52%，但一局变成约 12 轮、4 人局约 15.6 轮，代价太大，没有采用（§7）。

- 模拟器 `npm run sim` 与网页共用 `src/engine/`；每局随机分配元素和角色（角色朝向随机），所有座位都是同一种电脑。共同获胜每人记 1/k 胜；「座位」指行动顺序（D-39 – D-42）。
- 电脑按 §12 枚举所有合法行动，在隐藏信息的副本上执行后打分；权重经「电脑互打」校准（D-53、D-54，已确认）：

### 4.3 为什么逆位多了，局就会变长

3 人局里，让一个对手退 1 格，第三个人同样得利，所以它大约只值「自己前进半格」。电脑（以及会算账的玩家）只有在逆位的格数约为正位两倍时才会选逆位。调优过程中，逆位使用率每提高约 10 个百分点，3 人局就多约 1 轮。v5 选在逆位 26%、比 v4 多约 1.7 轮的位置。

## 6. 规则改动明细

### 6.1 v3 → v4（M1，已采纳）

S1 每轮轮换先手；S2 单体逆位改为作用于所有领先于你的玩家；M1–M18 角色数值（力量去护盾、命运之轮按较低点数前进、恋人不多走 1 格、星星补到 2、节制不抽牌、世界最多 8 格；隐士 / 皇后 / 教皇 / 女祭司 / 死神 / 恶魔加前进；皇帝点数视为 4；魔术师额外打出最多 2 张；正义至少 2 格、领先时前进 1 格；审判抽 2 张；月亮 +1 FP；倒吊人改为「先走、下回合迟缓」）。详见 decisions.md D-58。

### 6.2 v4 → v5：统一规则

- **R1 角色逆位只能指定一名领先于你的玩家**：没有人领先于你时，逆位不能用（置灰）。高塔、世界的逆位作用于所有领先于你的玩家；恶魔、月亮放陷阱，见 T1–T4。
- **R2 打领先者 +2**：目标是领先者（进度最高，并列也算）时，主效果 +2（每张卡写明加在哪个数字上）。**两人局没有这个加成**：两人局里领先于你的人永远就是领先者，加成失去区分作用。
- **R3 每个角色逆位都有位置后果**：后退、定身（跳过下次移动）、迟缓、走错路；扣 FP、弃牌、封印、枯竭、失神只作附加。
- **T1 陷阱经过即触发**：其他玩家自己移动（移动步、自己出的牌和技能）时经过或停在陷阱星座就触发；被别人推动、交换位置不触发。一次移动经过多个陷阱依次触发。
- **T2 放置者 +1 FP**：陷阱触发时放置者 +1 FP（被护盾挡下也算触发，陷阱照样消失）。
- **T3 陷阱放在领先于你的玩家前方 1–3 格**：和 R1 一致：你领先时不能放。没有这一条时，2 人局的月亮能每隔一回合在对手面前放陷阱，对手必然踩中。
- **T4 陷阱数值**：枷锁：下回合定身、失去 3 FP（对领先者失去 5 FP）。幻象：后退 4 格（对领先者 6 格），这次移动结束。
- **SH 护盾返还**：护盾到期时如果没挡到任何东西，返还 1 FP（D-59）。

## 7. 未解决的问题

1. **3 人局小阿卡纳正位 78%**（目标 ≤ 75%）。原因同 §4.3：小牌逆位只让领先者退 1 格（或迟缓、偷 1 FP），在 3 人局不划算。把「打领先者 +1」用到小牌和宫廷牌后能降到约 52%，但一局要多约 1.5 轮（4 人局多约 3 轮），所以没采用。可选：接受现状（2、4 人局都在范围内），或只给宝剑逆位加这一条。
2. **愚者** 3 人局 +4.4，在 ±5 以内但接近边缘：它几乎只用正位（「掷骰 +1」），调整步长最小也要 ±1 格，会跳到另一头。如需处理，可加条件「若你领先，不 +1」（未测）。
3. 2 人局轮换先手会出现同一人连续行动两次（0,1,1,0……）。座位胜率因此均等，但手感上需要在界面上提示「你连续行动」。
