# 平衡报告（M1）

> **2026-11-22 更新**：你已接受本报告的建议版，现在是引擎默认值（规则 v4，D-58）。角色逆位正按你的新原则重新设计，完成后会重新生成本报告。下文的「建议版」即现行 v4。

> 由 `npm run sim` 生成，共 172,000 局电脑对局，用时 272 秒，总种子 `wof`（同一种子可完整复现）。
> 「v3」= 规则书 v3 的数值；「建议版」= `src/sim/proposal.ts` 里的修改。建议版**没有**写进游戏默认值，等你确认后才改规则书和引擎。
> 角色胜率以 3 人 3 圈 20,000 局为准（每个角色约 2727 个样本，95% 误差约 ±1.8 个百分点）；其余组合各 2,000 局。

## 结论

1. **默认圈数：3 圈。** 3 人局平均 8.9 轮（v3 数值下 8.5 轮），落在 8–12 轮的目标内；2 圈只有 5.9 轮。设置里仍保留 1 / 2 / 3 圈。
2. **v3 有三个结构性问题**，单靠改卡牌数值解决不了：
   - **后手优势**：3 人局按行动顺序胜率 26% / 33% / 41%，4 人局 17% / 22% / 27% / 34%。「打完这一轮」消除了先手优势，却让最后行动的人有了「最后一句话」。→ 建议 **S1 每轮轮换先手**。
   - **多人局逆位太弱**：3 人局小阿卡纳 3% 打逆位、技能 9% 用逆位（§11 要求每边至少 25%）。只打一个对手时第三个人同样得利。→ 建议 **S2 单体逆位改为「所有领先于你的玩家」**。
   - **角色两极分化**：「直接前进」的技能远强于「给 FP / 手牌」的技能（每回合只能做一个行动，多出的牌和 FP 很难变成前进）。v3 有 18 个角色超出 ±7 个百分点，胜率从 14% 到 50%。→ 建议 **M1–M18 共 18 处角色数值**（宫廷牌和小阿卡纳数值不动）。
3. **建议版效果（3 人 3 圈）**：

| 指标 | v3 | 建议版 | 目标 |
| --- | --- | --- | --- |
| 按行动顺序的胜率 | 26% / 33% / 41% | 34% / 33% / 33% | 各约 33% |
| 角色胜率最大偏离 | ±19.6 | ±6.9 | ±7 以内 |
| 超出 ±7 的角色数 | 18 | 0 | 0 |
| 正位占比（小牌 / 宫廷 / 技能） | 97% / 77% / 91% | 78% / 76% / 96% | 每项 25%–75% |
| 平均轮数 | 8.6 | 8.9 | 8–12 |

4. **仍需你决定的问题**（详见 §7）：
   - 小阿卡纳和宫廷组合的正位占比：3 人局 78% / 76%，略超 75%；2 人、4 人局都在 25%–75% 内（§5.1）。
   - 3 人局所有角色都在 ±7 以内。
   - **技能仍有 96% 用正位**：多数角色的逆位是扣 FP、加状态，而这个游戏的胜负几乎只看前进，这类逆位怎么加强都比不过「自己前进」。要真正解决，需要把角色逆位重新设计成「让对手后退」为主——这属于卡牌创意，留给你决定。
   - 2 人和 4 人局个别角色偏离 10 个百分点左右（§4.2），原因可解释，可以接受，也可以像恋人那样加「两人局改为……」的变体。
   - **陷阱几乎消失**：建议版里恶魔、月亮都主要用正位，3 人局每局只放 0.03 个陷阱（v3 为 0.17），和上一条是同一个原因（§5.5）。
   - 星币、圣杯很少被直接打出，主要作为宫廷组合的材料（§5.4），建议保持。

## 1. 方法

- 模拟器 `npm run sim` 与网页共用 `src/engine/`。每局随机分配元素和角色（角色朝向随机），所有座位都是同一种电脑。统计口径见 decisions.md D-39 – D-42：共同获胜每人记 1/k 胜；「座位」指行动顺序。
- **电脑对手**按 §12 实现：枚举所有合法行动（每张牌的两面和每个目标、所有宫廷组合、技能的每种选择、冥想），在隐藏信息的副本上执行（牌堆重新洗过，偷看不到真实牌序），按估值打分取最高。在 §12 的基础上做了两处调整，**需要你确认**：
  - **D-53 加速和重掷**：§12 只在「离终点差 1 格」时加速，电脑会攒着用不掉的 FP（终局平均剩 5–6 点）。现在加速后仍有 ≥ 3 FP 就加速，最后一轮有 FP 就加速，掷到会踩对手陷阱时重掷或加速避开。
  - **D-54 估值权重**：§12「让对手后退 1 格 = 1.5 分」和 §10 的状态估值高估了攻击。用「电脑互打」校准：一个电脑用某组权重，其余用另一组，比较胜率。结果如下，现在电脑默认用「调整后权重」：对手 1 格 = 1.0 分（两人局仍是 2 分），对手身上的状态按 §10 的一半算；其余与 §12 相同。

| 对局 | 局数 | 主角胜率 | 公平值 | 95% 区间 |
| --- | --- | --- | --- | --- |
| 1 个调整后 vs 2 个 §12 原权重（3 人局） | 4000 | 39.0% | 33.3% | ±1.5 |
| 1 个 §12 原权重 vs 2 个调整后（3 人局） | 4000 | 26.3% | 33.3% | ±1.4 |
| 1 个调整后 vs 3 个 §12 原权重（4 人局） | 4000 | 33.0% | 25.0% | ±1.5 |
| 1 个调整后 vs 1 个 §12 原权重（2 人局） | 4000 | 52.5% | 50.0% | ±1.5 |

  互打说明两件事：调整后的电脑明显更强；而且在一群调整后的电脑里，用 §12 原权重的电脑会明显吃亏，说明这不是「坐收渔利」，而是更好的打法。平衡数据只有在电脑打得像样时才可信，所以本报告全部用调整后的电脑。

| 4 | 建议版 | 0.04 | 73.3% | 0.001 | 0.0% | 26.7% |

陷阱只来自恶魔和月亮的逆位。一旦放下，3–4 人局约一半以上会被触发，说明陷阱本身有用；2 人局只有一个可能踩中的人，触发率较低。**但建议版里陷阱很少被放下**：恶魔加了前进后几乎只用正位，月亮本来就以正位为主。这是 §7 第 1 条的一部分；如果希望陷阱更常见，最直接的办法是让恶魔、月亮的逆位在放陷阱之外再带一个小效果（例如「所有领先于你的玩家后退 1 格」）。

## 6. 修改建议明细

每一条都对应规则书的一句话。数值以「建议版 3 人局」为准；所有角色的完整数据见 §4。

**S1 每轮轮换先手**
- v3：行动顺序固定为火→土→风→水；有人到终点后打完这一轮（§3.5、§8）。
- 建议：元素顺序不变，但每一轮由下一位玩家先行动（实体版用一个「先手标记」每轮顺时针传一位）；仍然打完这一轮再结算，每人回合数相同。
- 理由：固定顺序下最后行动的人在最后一轮总有「最后一句话」：别人到终点后他还能出手，而他到终点后没人能回应。3 人局最后一位胜率 41%，第一位 26%。

**S2 单体逆位改为「所有领先于你的玩家」**
- v3：小阿卡纳、宫廷牌和多数角色的逆位作用于一名「目标玩家」。
- 建议：这些逆位改为作用于「所有领先于你的玩家」（进度比你高的人，不用再选目标）；没人领先于你时不能用（置灰）。例外：女祭司逆位（要看对方手牌）、恋人逆位（交换两人）保持指定目标；正义、皇帝逆位本来就打领先者，不变。
- 理由：3–4 人局里只打一个对手，第三个人同样受益，所以逆位几乎没人用（v3：3 人局小阿卡纳 97% 打正位）。改成打所有领先者后，强度随人数增长：2 人局效果不变，3–4 人局落后时一次能绊多人，领先时自然改用正位，正符合 §12「领先偏正位、落后偏逆位」，也更像赛车游戏的「龟壳」。

**M1 力量 正位**
- v3：前进到下一个火象星座，并获得护盾。
- 建议：前进到下一个火象星座。（去掉护盾）
- 理由：v3 中最强的角色。 3 人局胜率 50.0% → 37.4%（偏离 +16.7 → +4.1）。

**M2 命运之轮 正位**
- v3：掷两次：按较高点数前进，获得等于较低点数的 FP。
- 建议：掷两次：按**较低**点数前进，获得等于**较高**点数的 FP。
- 理由：偏强；交换后总量不变，前进少一些。 3 人局胜率 49.3% → 29.7%（偏离 +16.0 → −3.6）。

**M3 恋人 正位**
- v3：前进到前方 5 格内最近玩家所在的格子，再前进 1 格；否则前进 2 格。
- 建议：前进到那名玩家所在的格子（不再多走 1 格）；否则前进 2 格。
- 理由：偏强。 3 人局胜率 47.8% → 30.6%（偏离 +14.4 → −2.8）。

**M4 星星 正位**
- v3：前进到下一个水象星座；FP 少于 3 时补到 3。
- 建议：……FP 少于 **2** 时补到 2。
- 理由：偏强。 3 人局胜率 45.6% → 34.0%（偏离 +12.2 → +0.7）。

**M5 节制 正位**
- v3：前进到下一个水象星座，抽 1 张牌。
- 建议：前进到下一个水象星座。（不抽牌）
- 理由：偏强。 3 人局胜率 44.4% → 33.2%（偏离 +11.1 → −0.2）。

**M6 世界 正位**
- v3：每局一次：前进到双鱼座。
- 建议：每局一次：前进到双鱼座，**最多 8 格**。
- 理由：从白羊座出发一次走 11 格，偏强；上限 6 格时又偏弱。 3 人局胜率 49.0% → 33.4%（偏离 +15.6 → +0.0）。

**M7 隐士 正位**
- v3：获得 2 FP、抽 2 张牌、获得护盾。
- 建议：**前进 1 格**、获得 2 FP、抽 **1** 张牌、获得护盾。
- 理由：只给资源的技能明显吃亏：每回合只能做一个行动，多出的牌用不上。 3 人局胜率 26.6% → 33.6%（偏离 −6.7 → +0.2）。

**M8 皇后 正位**
- v3：获得 3 FP，抽 2 张牌。
- 建议：**前进 1 格**、获得 3 FP、抽 **1** 张牌。
- 理由：同上。 3 人局胜率 20.6% → 31.8%（偏离 −12.7 → −1.5）。

**M9 教皇 正位**
- v3：清除自己所有状态，获得 2 FP、抽 1 张、获得护盾。
- 建议：**前进 1 格**，其余不变。
- 理由：同上。 3 人局胜率 16.3% → 29.5%（偏离 −17.0 → −3.8）。

**M10 女祭司 正位**
- v3：看牌堆顶 3 张：用一张小牌的正位、拿一张入手，并获得 1 FP。
- 建议：**前进 1 格**，再看牌堆顶 3 张……（**不再** +1 FP）。
- 理由：同上。 3 人局胜率 24.0% → 31.7%（偏离 −9.3 → −1.6）。

**M11 死神 正位**
- v3：弃任意张、抽到 5 张、清除状态、获得 1 FP。
- 建议：**前进 2 格**，其余不变。
- 理由：v3 电脑几乎不用这个技能。 3 人局胜率 14.9% → 28.7%（偏离 −18.4 → −4.7）。

**M12 恶魔 正位**
- v3：获得 5 FP 并前进 1 格；你下回合枯竭。
- 建议：获得 5 FP 并前进 **2** 格；你下回合枯竭。
- 理由：偏弱。 3 人局胜率 14.8% → 35.2%（偏离 −18.5 → +1.9）。

**M13 皇帝 正位**
- v3：获得 2 FP 与护盾；本回合移动点数视为 3。
- 建议：获得 **1** FP 与护盾；本回合移动点数视为 **4**。
- 理由：偏弱。 3 人局胜率 26.0% → 30.7%（偏离 −7.4 → −2.7）。

**M14 魔术师 正位**
- v3：抽 2 张，可立即额外打出 1 张小阿卡纳。
- 建议：……可立即额外打出**最多 2 张**小阿卡纳。
- 理由：偏弱。 3 人局胜率 18.3% → 32.9%（偏离 −15.0 → −0.4）。

**M15 正义 正位**
- v3：不领先：前进与领先者距离的一半（进位，最多 5）；领先：获得 2 FP。
- 建议：不领先：前进一半（**至少 2**、最多 5）；领先：**前进 1 格**并获得 2 FP。
- 理由：偏弱；局面接近时一半距离往往只有 1 格。 3 人局胜率 29.5% → 28.8%（偏离 −3.9 → −4.5）。

**M16 审判 正位**
- v3：弃最多 4 张，每弃 1 张前进 1 格，然后抽 1 张。
- 建议：……然后抽 **2** 张。
- 理由：偏弱。 3 人局胜率 28.2% → 35.3%（偏离 −5.2 → +1.9）。

**M17 月亮 正位**
- v3：前进 2 格并获得护盾；到你下回合前陷阱无效。
- 建议：……并**获得 1 FP**。
- 理由：偏弱（FP 现在会被用来加速：约 2 FP = 1 格）。 3 人局胜率 30.5% → 34.9%（偏离 −2.8 → +1.5）。

**M18 倒吊人 正位**
- v3：本回合不移动；获得 4 FP、抽 2 张、获得护盾。
- 建议：**前进 2 格**、获得 3 FP、抽 1 张、获得护盾；**你下回合迟缓**。（「牺牲」从「现在不动」改为「先走、下回合付代价」）
- 理由：v3 胜率最低。一次拿很多 FP 消化不了（每回合最多加速一次），而「本回合不动」的代价是实打实的。 3 人局胜率 13.7% → 29.1%（偏离 −19.6 → −4.2）。

宫廷牌和小阿卡纳的**数值**不动（§11 的顺序：先角色、再宫廷、最后小牌）；它们只受 S2 影响（逆位改为打所有领先者）。

## 7. 未解决的问题与可选方案

1. **角色技能的逆位仍很少用**（建议版 3 人局 4%，陷阱因此也很少出现）。试过把角色逆位强度普遍提高到约两倍，占比几乎不变：多数角色逆位是扣 FP、加状态，而胜负几乎只看前进。只有「让对手后退」的逆位会被用（战车、教皇、倒吊人）。可选方案：把更多角色逆位改成「所有领先于你的玩家后退 N 格」再加原来的附带效果。这会改变不少卡的性格，需要你按塔罗含义来定。
2. **高塔**保持 v3 原样，3 人局偏离 +6.9。试过「再失去 1 FP」，会变成约 −8：1 FP 在当前打法里约值 7 个百分点，步长太粗。建议保持原样。
3. **2 人局**个别角色偏离 10–15 个百分点（§4.2）。如果你希望 2 人局也严格平衡，可以像恋人那样给少数角色加「两人局改为……」。
4. **规则书 §10 与 §12 的换算不一致**：§10 说 1 张牌 ≈ 0.5 格（即 1 分），§12 说 1 张牌 = 0.5 分。互打显示 §12 的 0.5 分更好（降到 0.25 会变弱），电脑沿用 §12。
