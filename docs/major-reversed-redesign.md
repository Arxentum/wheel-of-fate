## 1. 诊断：逆位是真的弱

做法：每个角色两组各 500 局（3 人 3 圈，现行 v4 规则），对手都是 2 个默认电脑。

- A 组：这个角色由默认电脑操作。
- B 组：这个角色「一律用逆位」：开局就是逆位、不翻回正位、能用逆位技能就用。

| | 默认电脑 | 一律逆位 | 差 |
|---|---|---|---|
| 22 个角色平均 | 33.6% | **7.5%** | −26.1 |
| 最好的（愚者 / 战车） | 42.1% / 35.6% | 17.2% / 17.2% | −24.9 / −18.4 |
| 最差的（恋人 / 女祭司） | 30.1% / 32.5% | 0.0% / 2.4% | −30.1 / −30.1 |

22 个角色**全部**明显变差（−15.6 到 −36.5 个百分点），所以不是电脑低估了逆位，而是逆位本身太弱。复现命令：`npm run sim -- --diagnose-reversed --games 500`。

## 2. 新的统一规则

### 2.1 角色逆位
1. **只能指定一名「领先于你的玩家」**（进度比你高）。没有人领先于你时，逆位不能用（置灰）。
2. **目标是领先者时，主效果 +1**。领先者 = 进度最高的玩家，并列也算。每张卡在表中写明 +1 加在哪个数字上。
3. **每个逆位都有位置后果**（后退、定身 = 跳过下次移动、迟缓、走错路），估值至少 1.5 格。扣 FP、弃牌、封印、枯竭、失神只作附加效果。
4. 例外：
   - **高塔、世界**：本来就是作用于「所有领先于你的玩家」的全体效果，保留，对其中的领先者 +1。
   - **恶魔、月亮**：放陷阱，见 2.2。
5. 小阿卡纳和宫廷牌的逆位**不在本次范围**，保持 v4（作用于所有领先于你的玩家）。角色逆位改完后，再重测「3 人局小牌正位 77%」。

### 2.2 陷阱（恶魔、月亮）
1. **经过即触发**：其他玩家**自己移动**（移动步、自己出的牌或技能）时，经过或停在陷阱所在的星座就会触发。被别人的效果推动、被交换位置，都不触发。
2. 一次移动经过多个陷阱时依次触发。幻象陷阱让人后退后，这次移动立刻结束。
3. **触发时放置者 +1 FP**（被护盾挡下也算触发，陷阱照样消失）。
4. 触发者是领先者时 +1：枷锁多失去 1 FP；幻象多后退 1 格。
5. 其余不变：放在任意没有陷阱的星座，全场最多 3 个，放置者自己不触发，月亮正位期间免疫。

### 2.3 护盾返还（已实现，D-59）
护盾到期时如果没挡到任何攻击，返还 1 FP。被攻击用掉的护盾不返还。

## 4. 关于数值

- 按调整后电脑的估值（D-54），「让对手退 1 格」大约等于「自己进 0.5 格」。所以要让逆位使用率达到 25–40%，逆位的格数大概要是正位的 1.5–2 倍。正位一般值 2–3 格。
- 表中数值按设定的下限设计（普通 2–3 格、对领先者 3–4 格），是**起点**。效果形式定下来后，再跑模拟只调数字，通常是给后退格数 +1，不改形式。
- 达标线：角色逆位使用率 25–40%；每局陷阱触发 ≥ 0.3 次；平均轮数不明显变长；3 人局每个角色在公平值 ±5 内，2 / 4 人局在 ±8 内。如果调数字达不到，带着数据重新讨论，不直接改效果形式。
- 小牌正位比例、2 / 4 人局偏差、高塔（只改效果幅度或加条件，不调费用）都等这一轮改完后再重测。
